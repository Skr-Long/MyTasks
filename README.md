# 水浒横版RPG冒险游戏 - 天罡地煞

基于Phaser.js + Nest.js开发的水浒横版格斗RPG游戏，采用火柴人美术风格。

## 技术栈

### 前端
- Phaser.js 3.80+ (游戏引擎)
- Vite 5.0+ (构建工具)
- TypeScript 5.1+
- Axios (HTTP请求)

### 后端
- NestJS 10+ (Node.js框架)
- MongoDB 6.0+ (数据库)
- Redis 7.0+ (缓存)
- JWT (认证)
- bcryptjs (密码加密)

## 快速开始

### 环境要求
- Node.js 20+
- MongoDB 6.0+ (本地或远程)

### 安装依赖

```bash
npm run install:all
```

### 启动开发服务器

1. 确保MongoDB服务正在运行

2. 启动后端服务（端口3001）：
```bash
npm run dev:backend
```

3. 启动前端服务（端口3000）：
```bash
npm run dev:frontend
```

4. 访问 http://localhost:3000 开始游戏

## 核心功能

### 1. 用户系统
- 用户注册/登录
- JWT认证保持登录状态
- 用户数据持久化

### 2. 角色系统
- 3名初始英雄：武松、鲁智深、林冲
- 每种英雄独特的武器和技能
- 火柴人风格绘制

### 3. 战斗系统
- 横版格斗玩法
- 移动：A/D键
- 跳跃：W键
- 攻击：J键（支持连击）
- 技能：K键
- 敌人AI巡逻/追击/攻击
- 血条UI显示

### 4. 副本系统
- 景阳冈（简单）
- 清风寨（普通）
- 祝家庄（困难）
- 曾头市（困难）
- 梁山泊（困难）

## 操作说明

| 按键 | 功能 |
|------|------|
| A / D | 左右移动 |
| W | 跳跃 |
| J | 普通攻击 |
| K | 技能释放 |
