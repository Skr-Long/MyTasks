# 水浒横版RPG冒险游戏 - 火柴人风格实现方案

## 一、为什么选择火柴人风格？

### 1.1 核心优势

✅ **零美术资源依赖**：全部用代码绘制，不需要任何图片资源
✅ **开发速度极快**：几天就能做出完整战斗原型
✅ **性能极佳**：纯矢量绘制，CPU/GPU占用极低
✅ **风格独特**：简约而不简单，辨识度高
✅ **便于迭代**：修改参数就能调整外观，不需要重绘

### 1.2 效果预期

**简约但不简陋**：
- 用粗细线条表现角色特征
- 用颜色区分品质/职业
- 用粒子特效增强打击感
- 用流畅动画弥补简约

## 二、火柴人角色设计规范

### 2.1 基础火柴人结构

```
    ○ 头部（圆形）
   /|\ 身体+手臂
   / \ 腿部
```

**基础绘制参数**：
- 线宽：3-5px
- 身高：100-150px
- 比例：头:身:腿 = 1:2:2

### 2.2 角色差异化设计

#### 颜色区分品质

| 品质 | 主色 | 描边色 | 特效色 |
|------|------|--------|--------|
| R | 灰色 | 深灰 | 无 |
| SR | 蓝色 | 深蓝 | 淡蓝光晕 |
| SSR | 紫色 | 深紫 | 紫色粒子 |
| UR | 金色 | 橙金 | 金色星光 |

#### 造型区分职业

**力量型（鲁智深、李逵）**：
- 线条加粗（线宽6-8px）
- 身体比例更宽
- 手臂肌肉用弧线表现
- 武器：禅杖/双斧（简化几何形）

**敏捷型（燕青、花荣）**：
- 线条纤细（线宽2-3px）
- 身体修长
- 腿部比例更长
- 武器：弓/弩（线条勾勒）

**技巧型（吴用、公孙胜）**：
- 线条飘逸
- 有披风/羽扇装饰
- 周身有法阵光环
- 武器：羽扇/拂尘

**均衡型（武松、林冲）**：
- 标准线宽（4-5px）
- 比例匀称
- 有头巾/头箍装饰
- 武器：双刀/长枪

### 2.3 重点角色火柴人设计

**武松（UR-天伤星）**：
- 头箍：头顶一个小矩形
- 戒刀：双手各持一把弯刀（弧线+直线）
- 觉醒：全身金色，双臂有火焰状线条
- 醉拳：身体略微倾斜，周围有酒滴粒子

**鲁智深（UR-天孤星）**：
- 光头：圆形略大
- 佛珠：胸前一串小圆圈
- 禅杖：长棍+月牙形端头
- 金身：全身粗线，边缘有金光

**林冲（SSR-天雄星）**：
- 豹头：头部画几道折线表现鬃毛
- 长枪：长直线+枪尖三角形
- 风雪：周围有飘落的斜线条

## 三、Web技术实现方案

### 3.1 技术选型

**核心渲染引擎**：Phaser 3.x
- 内置Canvas/WebGL渲染
- 支持Graphics绘图API
- 动画系统完善
- 性能优化到位

**辅助库**：
- `matter-js`：物理引擎（可选，用于 ragdoll 效果）
- `tween.js`：补间动画
- `pixi.js`：备选渲染引擎

### 3.2 基础绘制代码示例

```typescript
// Phaser 3 火柴人基础绘制
class StickFigure extends Phaser.GameObjects.Container {
  constructor(scene: Phaser.Scene, x: number, y: number) {
    super(scene, x, y);
    
    // 创建 Graphics 对象
    const graphics = scene.add.graphics();
    this.add(graphics);
    
    this.drawFigure(graphics);
  }
  
  drawFigure(graphics: Phaser.GameObjects.Graphics) {
    // 清除
    graphics.clear();
    
    // 设置样式
    graphics.lineStyle(4, 0xffffff, 1);
    
    // 头部 (圆形)
    graphics.strokeCircle(0, -40, 15);
    
    // 身体 (直线)
    graphics.lineBetween(0, -25, 0, 20);
    
    // 左臂
    graphics.lineBetween(0, -20, -25, 0);
    
    // 右臂
    graphics.lineBetween(0, -20, 25, 0);
    
    // 左腿
    graphics.lineBetween(0, 20, -15, 50);
    
    // 右腿
    graphics.lineBetween(0, 20, 15, 50);
  }
}
```

## 四、动画系统实现

## 五、火柴人特效系统

### 5.1 打击特效（纯代码绘制）

**命中闪光**：
```typescript
createHitEffect(x: number, y: number) {
  const graphics = this.scene.add.graphics();
  
  // 闪光圆圈
  graphics.fillStyle(0xffffff, 1);
  graphics.fillCircle(x, y, 20);
  
  // 淡出动画
  this.scene.tweens.add({
    targets: graphics,
    alpha: 0,
    scale: 2,
    duration: 200,
    onComplete: () => graphics.destroy()
  });
}
```

**斩击线**：
```typescript
createSlashEffect(x: number, y: number, angle: number) {
  const graphics = this.scene.add.graphics();
  
  graphics.lineStyle(3, 0xffffff, 1);
  
  // 弧形斩击线
  const arc = new Phaser.Curves.Ellipse(x, y, 50, 20, angle - 45, angle + 45);
  graphics.strokePoints(arc.getPoints(32));
  
  // 快速消失
  this.scene.tweens.add({
    targets: graphics,
    alpha: 0,
    duration: 150,
    onComplete: () => graphics.destroy()
  });
}
```

### 5.2 星宿觉醒特效

```typescript
createStarAwakeEffect(character: Phaser.GameObjects.Container) {
  // 星芒环绕
  for (let i = 0; i < 8; i++) {
    const angle = (i / 8) * Math.PI * 2;
    const star = this.createStarParticle();
    
    this.scene.tweens.add({
      targets: star,
      x: character.x + Math.cos(angle) * 60,
      y: character.y + Math.sin(angle) * 60,
      duration: 1000,
      repeat: -1,
      ease: 'Linear'
    });
  }
}

createStarParticle(): Phaser.GameObjects.Graphics {
  const g = this.scene.add.graphics();
  g.fillStyle(0xffd700, 1);
  // 画四角星
  g.fillPoints([
    {x: 0, y: -8}, {x: 3, y: -3}, {x: 8, y: 0},
    {x: 3, y: 3}, {x: 0, y: 8}, {x: -3, y: 3},
    {x: -8, y: 0}, {x: -3, y: -3}
  ], true);
  return g;
}
```

```typescript
createForestScene() {
  const graphics = this.scene.add.graphics();
  
  // 地面
  graphics.fillStyle(0x3d5c3d, 1);
  graphics.fillRect(0, 450, 800, 150);
  
  // 松树（三角形堆叠）
  this.drawPineTree(graphics, 100, 450);
  this.drawPineTree(graphics, 300, 450);
  this.drawPineTree(graphics, 600, 450);
}

drawPineTree(graphics: Phaser.GameObjects.Graphics, x: number, y: number) {
  graphics.fillStyle(0x2d4a2d, 1);
  
  // 三层三角形
  graphics.fillTriangle(x, y - 80, x - 30, y - 40, x + 30, y - 40);
  graphics.fillTriangle(x, y - 60, x - 25, y - 25, x + 25, y - 25);
  graphics.fillTriangle(x, y - 40, x - 20, y - 10, x + 20, y - 10);
  
  // 树干
  graphics.fillStyle(0x5c4033, 1);
  graphics.fillRect(x - 5, y - 10, 10, 10);
}
```

## 七、UI火柴人风格

### 7.1 UI设计原则

**简约几何**：全部用矩形、圆形、线条构成
**书法感**：按钮边框用毛笔笔触效果（粗线条）
**印章风**：评级用红色圆形印章

### 7.2 火柴人血条

```typescript
class StickHealthBar {
  private graphics: Phaser.GameObjects.Graphics;
  
  drawHealth(current: number, max: number) {
    this.graphics.clear();
    
    // 背景条（灰色）
    this.graphics.fillStyle(0x333333, 1);
    this.graphics.fillRect(0, 0, 200, 20);
    
    // 血条（绿色→红色渐变）
    const percent = current / max;
    const color = Phaser.Display.Color.Interpolate.ColorWithColor(
      {r: 255, g: 0, b: 0},    // 红色
      {r: 0, g: 255, b: 0},    // 绿色
      100, percent * 100
    );
    
    this.graphics.fillStyle(Phaser.Display.Color.GetColor(color.r, color.g, color.b), 1);
    this.graphics.fillRect(2, 2, (200 - 4) * percent, 16);
    
    // 边框（粗线条）
    this.graphics.lineStyle(3, 0xffffff, 1);
    this.graphics.strokeRect(0, 0, 200, 20);
  }
}
```
