---

- 纯前端，无后端
- Phaser.js：2D游戏逻辑

## 基本约定

### 目录结构
```
src/
├── core/          # 核心逻辑（双引擎协调）
├── game/          # 游戏逻辑（塔、敌人、技能、系统）
├── ui/            # UI界面
├── config/        # 配置文件
├── assets/        # 资源（模型、纹理、音频、图片）
└── utils/         # 工具函数
```

### 代码规范
- TypeScript 严格模式
- 类名：PascalCase
- 方法/变量：camelCase
- 常量：UPPER_SNAKE_CASE

### 数据约定
- 格子大小：64x64 像素
- 数值全部使用 JSON 配置

### Git 提交
- feat: 新功能
- fix: 修复bug
- docs: 文档
- style: 格式调整
- refactor: 重构
- perf: 性能优化
- test: 测试

## 注意事项
- 纯前端，数据存本地
- 性能优先，控制3D复杂度

- Phaser逻辑与Three渲染解耦
