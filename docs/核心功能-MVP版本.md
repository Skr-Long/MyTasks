# 水浒横版RPG冒险游戏 - 核心功能（MVP版本）

## 二、核心功能（MVP版本）

### 2.1 用户注册与登录功能

**账号注册**：支持用户名密码注册，包含用户名唯一性校验、密码强度验证、基础用户信息初始化。注册成功后可选择初始武将伙伴。

**账号登录**：支持用户名密码登录，登录状态保持7天，会话管理采用JWT + Redis双验证机制，单点登录限制，异常登录提醒。

**游客模式**：无需注册即可体验前3章剧情，游客进度本地存储，绑定正式账号后数据迁移。

### 2.2 战斗系统

**战斗场景**：横版卷轴地图，包含地面、多层平台、可破坏障碍物，支持左右移动、跳跃、场景互动。经典场景：景阳冈松林、祝家庄庄院、曾头市校场、大名府街道。

**角色操作**：八方向移动、二段跳跃、普通攻击三连击、技能释放（4个主动技能）、闪避翻滚、受身反击、格挡防御。

**武将战斗**：每个武将拥有独特战斗风格：
- **力量型**（鲁智深、李逵）：高攻击高血量，范围伤害
- **敏捷型**（燕青、石秀）：高速高暴击，连击伤害
- **技巧型**（吴用、公孙胜）：控制技能，辅助效果
- **均衡型**（林冲、武松）：攻防兼备，适应性强

**敌人系统**：
- **普通怪物**：庄客、士兵、山贼，基础AI巡逻与追击
- **精英怪物**：祝氏三杰、曾家五虎，特殊技能
- **BOSS**：祝家庄栾廷玉、曾头市史文恭，阶段变换机制

**战斗机制**：
- 伤害计算：攻击-防御+属性相克
- 暴击判定：150%-200%伤害，暴击率受武将资质影响
- 硬直状态：受击后短暂无法行动
- 浮空状态：可进行空中连击
- 倒地状态：保护机制，起身无敌帧
- 连击计数：连击越高伤害加成越高，最高50连50%加成

**战斗UI**：
- 角色血条 + 内力条 + 怒气条
- 技能图标与冷却倒计时
- 连击数显示 + 评价系统（完美/优秀/良好）
- 伤害数字飘字（暴击金色、真实伤害紫色）
- 伙伴头像与状态显示

### 2.3 伙伴系统（新增）

**伙伴获取**：
- 初始选择：武松、鲁智深、林冲三选一
- 剧情解锁：完成主线关卡自动加入
- 酒馆招募：消耗酒券抽取，R/SR/SSR/UR四个稀有度
- 活动获取：限时活动、节日活动专属武将

**伙伴培养**：
- **等级提升**：消耗经验丹，最高等级=玩家等级
- **升星进阶**：消耗同名碎片，最高5星，解锁天赋技能
- **技能升级**：消耗技能书，提升技能效果
- **装备穿戴**：6件装备，套装效果加成
- **羁绊系统**：特定武将同时上阵激活羁绊属性（如：鲁智深+武松=生死之交）

**伙伴出战**：
- 最多3名伙伴同时出战
- 1名主控角色 + 2名AI伙伴
- 可随时切换主控角色
- 伙伴AI策略可设置（进攻型/防守型/辅助型）

### 2.4 组队副本系统（新增）

**副本类型**：
- **剧情副本**：单人/组队均可，推进主线剧情
- **材料副本**：每日限定次数，掉落培养材料
- **装备副本**：组队挑战，掉落高品质装备
- **活动副本**：限时开放，稀有奖励

**多人组队**：
- 最多3人组队
- 实时匹配或邀请好友
- 队伍配置：1坦克+1输出+1辅助最优
- 队长可设置进入条件（等级、战力）

**人机组队**：
- 玩家 + 2名AI伙伴
- AI伙伴可选择已拥有的武将
- 难度自适应，奖励略低于真人组队
- 适合单人玩家挑战高难副本

**副本结算**：
- 通关评价：S/A/B/C/D，影响奖励倍率
- 翻牌奖励：3选1，有几率获得稀有物品
- 经验结算：按贡献分配
- roll点系统：稀有物品roll点分配
