# 水浒横版RPG冒险游戏 - 完整功能模块（后续迭代）

## 四、完整功能模块（后续迭代）

### 4.1 武将系统模块

**武将基础属性**：
- 等级、经验、星级、品质
- 战力、生命、攻击、防御
- 速度、暴击率、暴击伤害
- 内力、怒气恢复

**技能系统**：
- 天赋技能：自动解锁，被动效果
- 3个主动技能：可升级，不同效果
- 怒气大招：消耗怒气，高伤害/强控制
- 技能自由搭配：可选择携带技能

**武将获取**：
- 初始选择：三选一
- 剧情解锁：主线关卡
- 聚义堂招募：酒券抽取
- 梁山活动：限时获取
- 碎片合成：收集碎片合成

**武将养成**：
- 等级升级：经验丹
- 星级提升：同名碎片
- 技能升级：技能书
- 潜能激发：消耗潜能丹，属性百分比加成
- 觉醒系统：UR品质可觉醒，解锁新形态

### 4.2 装备系统模块

**装备类型**：武器、头盔、护甲、靴子、项链、戒指。

**装备品质**：白<绿<蓝<紫<橙<红，6种品质分级。

**装备养成**：
- **强化系统**：消耗金币，最高+20，强化等级可传承
- **宝石镶嵌**：每件装备3个孔位，宝石可摘除
- **属性洗练**：洗练石重置副属性，锁定极品属性
- **套装效果**：2件/4件/6件激活套装效果
- **装备锻造**：材料合成高级装备

### 4.3 副本系统模块

**副本类型**：
- **剧情副本**：10章主线，每章10小关
- **聚义副本**：组队挑战，掉落武将碎片
- **兵工厂**：装备材料副本
- **丹药房**：经验丹药副本
- **竞技场**：实时PVP
- **梁山守卫战**：塔防模式

**副本难度**：普通、困难、噩梦、地狱，4种难度选择。

**副本机制**：
- 限时挑战
- 成就系统（无伤通关、限时通关）
- 扫荡功能：S评价可扫荡
- 次数限制：每日重置

### 4.4 社交系统模块

**好友系统**：
- 添加删除好友
- 在线状态显示
- 私聊功能
- 组队邀请
- 体力赠送（每日5次）
- 友情点兑换

**军团系统**：（新增，替换公会）
- 创建加入军团
- 军团等级、军团贡献
- 军团商店：贡献兑换
- 军团技能：全体成员加成
- 军团战：跨服军团对战
- 军团副本：组队挑战
- 军团BOSS：全军团共同挑战

**聊天系统**：
- 世界频道
- 军团频道
- 队伍频道
- 私聊频道
- 表情系统
- 快捷语音

### 4.5 经济与活动模块

**货币系统**：
- 铜钱：普通消耗
- 元宝：充值货币
- 绑定元宝：任务奖励
- 军团贡献：军团玩法
- 友情点：好友互动

**商城系统**：
- 普通商城：铜钱购买
- 元宝商城：元宝购买
- 绑定商城：绑定元宝
- 军团商城：贡献兑换
- 限时商城：打折商品
- 神秘商人：随机刷新

**签到日常**：
- 每日签到：累计奖励
- 日常任务：10个任务
- 活跃度宝箱：100活跃度
- 周常任务：每周重置

**限时活动**：
- 节日活动：春节、中秋等
- 版本活动：新版本福利
- 累计充值：充值返利
- 双倍活动：经验、掉落双倍
- 限时招募：UP武将
