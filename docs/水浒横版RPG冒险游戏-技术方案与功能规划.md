# 水浒横版RPG冒险游戏 - 技术方案与功能规划

## 一、游戏世界观与背景设定

### 1.1 游戏背景
以北宋末年为时代背景，玩家以江湖侠客身份卷入梁山聚义的历史洪流。从景阳冈起步，历经清风寨、祝家庄、曾头市、大名府等经典场景，与水浒一百单八将共同谱写替天行道的英雄史诗。

### 1.2 核心剧情线
- **第一章：初入江湖** - 景阳冈打虎，结识武松，开启江湖之旅
- **第二章：义薄云天** - 大闹清风寨，花荣、秦明入伙
- **第三章：祝家庄风云** - 三打祝家庄，收编扈三娘、孙立
- **第四章：曾头市复仇** - 晁盖中箭，卢俊义上山
- **第五章：大聚义** - 一百单八将排座次，替天行道大旗升起

## 二、核心功能（MVP版本）

### 2.1 用户注册与登录功能

**账号注册**：支持用户名密码注册，包含用户名唯一性校验、密码强度验证、基础用户信息初始化。注册成功后可选择初始武将伙伴。

**账号登录**：支持用户名密码登录，登录状态保持7天，会话管理采用JWT + Redis双验证机制，单点登录限制，异常登录提醒。

**游客模式**：无需注册即可体验前3章剧情，游客进度本地存储，绑定正式账号后数据迁移。

### 2.2 战斗系统

**战斗场景**：横版卷轴地图，包含地面、多层平台、可破坏障碍物，支持左右移动、跳跃、场景互动。经典场景：景阳冈松林、祝家庄庄院、曾头市校场、大名府街道。

**角色操作**：八方向移动、二段跳跃、普通攻击三连击、技能释放（4个主动技能）、闪避翻滚、受身反击、格挡防御。

**武将战斗**：每个武将拥有独特战斗风格：
- **力量型**（鲁智深、李逵）：高攻击高血量，范围伤害
- **敏捷型**（燕青、石秀）：高速高暴击，连击伤害
- **技巧型**（吴用、公孙胜）：控制技能，辅助效果
- **均衡型**（林冲、武松）：攻防兼备，适应性强

**敌人系统**：
- **普通怪物**：庄客、士兵、山贼，基础AI巡逻与追击
- **精英怪物**：祝氏三杰、曾家五虎，特殊技能
- **BOSS**：祝家庄栾廷玉、曾头市史文恭，阶段变换机制

**战斗机制**：
- 伤害计算：攻击-防御+属性相克
- 暴击判定：150%-200%伤害，暴击率受武将资质影响
- 硬直状态：受击后短暂无法行动
- 浮空状态：可进行空中连击
- 倒地状态：保护机制，起身无敌帧
- 连击计数：连击越高伤害加成越高，最高50连50%加成

**战斗UI**：
- 角色血条 + 内力条 + 怒气条
- 技能图标与冷却倒计时
- 连击数显示 + 评价系统（完美/优秀/良好）
- 伤害数字飘字（暴击金色、真实伤害紫色）
- 伙伴头像与状态显示

### 2.3 伙伴系统（新增）

**伙伴获取**：
- 初始选择：武松、鲁智深、林冲三选一
- 剧情解锁：完成主线关卡自动加入
- 酒馆招募：消耗酒券抽取，R/SR/SSR/UR四个稀有度
- 活动获取：限时活动、节日活动专属武将

**伙伴培养**：
- **等级提升**：消耗经验丹，最高等级=玩家等级
- **升星进阶**：消耗同名碎片，最高5星，解锁天赋技能
- **技能升级**：消耗技能书，提升技能效果
- **装备穿戴**：6件装备，套装效果加成
- **羁绊系统**：特定武将同时上阵激活羁绊属性（如：鲁智深+武松=生死之交）

**伙伴出战**：
- 最多3名伙伴同时出战
- 1名主控角色 + 2名AI伙伴
- 可随时切换主控角色
- 伙伴AI策略可设置（进攻型/防守型/辅助型）

### 2.4 组队副本系统（新增）

**副本类型**：
- **剧情副本**：单人/组队均可，推进主线剧情
- **材料副本**：每日限定次数，掉落培养材料
- **装备副本**：组队挑战，掉落高品质装备
- **活动副本**：限时开放，稀有奖励

**多人组队**：
- 最多3人组队
- 实时匹配或邀请好友
- 队伍配置：1坦克+1输出+1辅助最优
- 队长可设置进入条件（等级、战力）

**人机组队**：
- 玩家 + 2名AI伙伴
- AI伙伴可选择已拥有的武将
- 难度自适应，奖励略低于真人组队
- 适合单人玩家挑战高难副本

**副本结算**：
- 通关评价：S/A/B/C/D，影响奖励倍率
- 翻牌奖励：3选1，有几率获得稀有物品
- 经验结算：按贡献分配
- roll点系统：稀有物品roll点分配

## 三、技术方案

### 3.1 前端技术方案

**核心引擎**：Phaser.js负责2D游戏逻辑，Three.js负责3D场景渲染。

**渲染架构**：分层设计
- 3D背景层：场景建筑、远景、动态天气
- 游戏对象层：角色、怪物、技能特效
- UI层：HUD、技能栏、聊天框
- 实现2.5D视觉效果，正交相机45度俯角

**坐标系统**：2D与3D映射转换，Z轴位置和缩放营造深度感，Y轴对应跳跃高度。

**工程化**：
- TypeScript 5.0+ 开发
- Vite 5.0 构建工具
- ESLint + Prettier 代码规范
- Husky + lint-staged 提交校验

**性能优化**：
- 对象池复用游戏对象（怪物、特效、伤害数字）
- 视口剔除只渲染屏幕内元素
- Web Worker处理路径计算、AI逻辑
- 资源预加载 + 懒加载
- 帧率自适应（30/60帧切换）

### 3.2 后端技术方案

**服务端**：Node.js 20+运行时，NestJS作为Web框架，TypeScript全栈开发。

**数据库**：
- MongoDB 6.0：存储用户数据、武将信息、装备详情
- Redis 7.0：缓存会话、排行榜、在线用户
- 数据备份：每日自动备份，保留7天

**实时通信**：Socket.io实现WebSocket连接，处理战斗同步与实时交互。

**架构设计**：
- **API网关**：路由分发、鉴权、限流、日志
- **用户服务**：注册登录、用户信息、好友系统
- **游戏服务**：战斗计算、副本管理、组队匹配
- **数据服务**：数据库操作、缓存管理
- **聊天服务**：实时消息、频道管理

**部署方案**：
- Docker容器化部署
- Nginx反向代理 + 负载均衡
- PM2进程管理
- 支持水平扩展

### 3.3 网络通信方案

**非实时数据**：RESTful HTTP接口
- 用户注册登录
- 信息查询
- 商城购买
- 邮件系统

**实时战斗**：Socket.io事件通信
- 操作指令传输（移动、攻击、技能）
- 战斗状态同步（位置、血量、CD）
- 组队匹配、房间管理
- 聊天消息

**战斗同步**：
- 服务端权威模式，所有伤害计算与碰撞检测在服务端执行
- 客户端输入预测 + 插值平滑
- 每秒15次状态广播
- 丢包重传机制
- 延迟补偿算法

**武将基础属性**：

- 怒气大招：消耗怒气，高伤害/强控制
- 技能自由搭配：可选择携带技能

**武将获取**：
- 初始选择：三选一

- 聚义堂招募：酒券抽取
